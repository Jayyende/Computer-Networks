# Experiment 12: Case Study on Computer Networks Laboratory Equipment and Connections

## Aim
To study Computer Networks Laboratory equipment and networking information and understand how computers and devices are connected to form a Local Area Network (LAN).

## 1. Introduction
A Computer Networks Laboratory is a place where multiple computers and networking devices are connected to communicate and share resources.

A Local Area Network (LAN) connects computers and other devices within a limited geographical area, such as a laboratory, office, or college.

In a computer laboratory, desktop computers are connected through network cables to a switch. The switch connects to a router, which helps communicate with other networks and provides internet access when configured.

## 2. Networking Equipment Used

### 1. Modem
A modem connects the local network to an Internet Service Provider (ISP). It converts signals into a suitable form for communication over the service provider's connection and provides internet connectivity.

### 2. Router
A router connects the LAN to other networks and forwards data packets between networks. It can provide internet access, DHCP, and Wi-Fi services depending on its configuration.

### 3. Switch
A switch connects multiple computers and devices within a LAN. It forwards data to the appropriate device using MAC addresses.

### 4. Desktop Computers
Desktop computers are end devices used by students for practicals, programming, and other networking activities. They communicate with other devices through the network.

### 5. Smart Board
A smart board is an interactive display used for teaching, presentations, and demonstrations. It may connect to the network for accessing online resources and sharing content.

### 6. LAN Cable (UTP)
UTP stands for Unshielded Twisted Pair. It is a commonly used Ethernet cable for connecting computers, switches, and routers. It contains four twisted pairs of wires.

Common categories include:
- Cat5e
- Cat6

### 7. RJ45 Connector
An RJ45-style 8P8C connector is used to terminate Ethernet cables. It connects the internal wires of a UTP cable to network devices.

### 8. Network Interface Card (NIC)
A Network Interface Card is a hardware component that enables a computer to connect to a network. It uses a MAC address to identify the network interface and send or receive data.

## 3. Working of LAN in the Computer Laboratory

The laboratory network works through the following steps:

1. Desktop computers are connected to a network switch using UTP Ethernet cables.
2. The smart board can also be connected to the network if network connectivity is required.
3. The switch connects to the router through an Ethernet cable.
4. The router connects the local network to other networks and provides internet connectivity when configured.
5. When one computer sends data to another device in the same LAN, the switch forwards the data using MAC addresses.
6. When a computer communicates with a device outside the local network, the router forwards the packets towards the destination network.
7. All connected devices can communicate and share available network resources according to the network configuration.

## 4. Network Topology

Network topology refers to the physical or logical arrangement of devices in a computer network.

### Star Topology
In a star topology, all computers and devices are connected to a central switch or hub.

**Features:**
- Each device has a separate connection to the central switch.
- Easy to manage and troubleshoot.
- Failure of one cable generally affects only the connected device.
- Failure of the central switch can affect the entire connected network.

A laboratory network using a central switch commonly follows a star topology.

## 5. Important Networking Terms

### 1. LAN (Local Area Network)
A network that connects computers and devices within a limited geographical area, such as a computer laboratory.

### 2. IP Address
An IP address is a logical address assigned to a network device for communication over an IP network.

### 3. MAC Address
A MAC address is a hardware-level address associated with a network interface and is used for communication within a local network.

### 4. DHCP (Dynamic Host Configuration Protocol)
DHCP automatically assigns IP addresses and other network configuration details to devices.

### 5. DNS (Domain Name System)
DNS converts human-readable domain names into IP addresses.

### 6. Gateway
A default gateway is the router or other device through which a computer sends traffic destined for other networks.

### 7. Bandwidth
Bandwidth refers to the data-carrying capacity of a network connection.

### 8. Ethernet
Ethernet is a commonly used technology for wired LAN communication.
